# 📱 smart-screen-nav 使用手册（新手友好版）

> **这是什么？**
> `smart-screen-nav` 是一个能让 AI **在手机上自动帮你点屏幕、找文件、做操作**的"技能（Skill）"。装好之后，你对 AI 说句"帮我打开 XX"或"定位到 XX 行"，它就能像人手一样操作手机屏幕。

> **适合谁？** 完全没接触过的新手也看得懂。文中的每一步都按"手指点哪里"写清楚。

## 一、安装导入

### 方式 A：本地 ZIP 导入（推荐）
1. 拿到技能压缩包 `smart-screen-nav-skill.zip`（一般存放在 `Download/Operit/skill-data/smart-screen-nav/发行/` 目录）。

2. 打开手机上的 **Operit** App → 进入 **技能（Skills）** 页面。

3. 点 **「导入技能」** → 在文件浏览器里找到并选中 `smart-screen-nav-skill.zip`。

4. 导入成功后，技能列表里会出现 **smart-screen-nav**（智能屏幕识别与最优路径）。

> ✅ 导入即生效，无需额外配置。首次使用会自动在手机里建立"经验库"文件夹。

**操作示意**
```
Operit → 技能 → [导入技能] → 选 smart-screen-nav-skill.zip → 完成
```

### 方式 B：从 GitHub 获取（分享/换机）
1. 用浏览器打开仓库：
   `https://github.com/haoyichao/operit-skills`
2. 点绿色按钮 **`<> Code`** → **Download ZIP**，把整个仓库下载到手机。
3. 解压后，进入 `smart-screen-nav/`，按上面 **方式 A 的第 2~4 步**导入（用 zip 或直接把 SKILL.md 等放入即可，若 Operit 支持目录导入建议打包 zip）。

## 二、第一次使用

### 怎么触发？
在 Operit 对话里，用正常的话说需求即可，例如：
- "帮我打开微信"
- "帮我在手机里找到 xxx 文件"
- "定位到第 124 行"
- "帮我把这个文件分享到浏览器打开"

AI 会自动：
1. **看清屏幕**（读取当前界面元素）
2. **规划最省事路径**（能一条命令直达就绝不多点几下）
3. **一步步点，每步截图确认**（不会盲目乱点）
4. **成功后把方法记下来**，下次更快。

> 💡 高亮：它**绝不会**像脚本那样盲点，而是"看得见、确认过、才动手"。

## 三、方案选择（进阶，可跳过）
当任务比较复杂（需要点好几下屏幕），AI 可能会**轻轻问一次**你想用哪种方案执行：

| 方案 | 名字 | 一句话理解 |
|---|---|---|
| 回车（默认） | 智能混合 | AI 自动挑最优，最省事 |
| 1 | 系统框架 API 直调 | 直接用系统命令，最快最准 |
| 2 | 预置脚本快路径 | 以前走过就直接照抄，秒执行 |
| 3 | 全量人工注入 | 完全像人手一样慢慢点 |
| 4 | 混合分层 | 2+3 结合，日常首选 |
| 5 | 虚拟显示注入 | 后台偷偷操作（需 root，一般不选） |

- **不选也行**：直接回车，AI 默认智能混合，不会打扰你。
- 选了之后 AI 会**记住**，下次不重复问；想改随时说"换方案 3"。

> 💡 新手可以完全不用管这个，默认就很聪明。

## 四、经验自动沉淀
- 每次 AI **成功**做完一件事（比如成功打开某文件），它会把"正确做法"记进**经验库**。
- 以后再遇到同一件事，就能**直接照做、秒完成**，不用每次从头想。
- 经验分成两种：
  - **通用经验**：换台手机也适用（如"怎么定位文件"）→ 会跟着技能一起保存/分享。
  - **个人经验**：只跟你的手机有关 → 只留在你这台手机。

> 你完全不用手动操作，AI 会自动管理，越用越顺手。

## 五、常见问题 FAQ

**Q1：导入后 AI 不响应"屏幕操作"？**
A：试试说更明确的话，如"帮我打开 XX"，或确认技能已启用。若仍不行，重启一次 Operit 再试。

**Q2：导入时提示 zip 有问题？**
A：确认文件是 `smart-screen-nav-skill.zip`（不要解压成文件夹再选），重新下载/导入一次。

**Q3：AI 点错界面卡住了？**
A：直接告诉它"你点错了/走错界面了"，并说明你**想**到哪。它会把这次纠正记进经验，下次不再犯错。

**Q4：屏幕上的坐标/按钮位置会不会每次都一样？**
A：不会。AI 每次都会**重新读取当前屏幕真实位置**，绝不用写死的坐标，所以换机型、换系统都稳。

**Q5：这需要 root 吗？**
A：日常使用**不需要** root。只有方案 5（虚拟显示）才可能需要，新手不用选它。
